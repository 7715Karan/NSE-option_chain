This project scrapes real-time Options Chain data from the National Stock Exchange of India (NSE) using Python and the requests library.
The data is processed into a clean DataFrame for further analysis, visualization, or trading strategy development.


Key Features
Real-time Options Chain data for NIFTY or BANKNIFTY

Extracts strike prices, open interest, change in OI, volume, implied volatility (IV), etc.

Automatically detects the nearest expiry

Data organized in tabular format (pandas DataFrame)

Simple and beginner-friendly code

Perfect for options analytics dashboards or trading bots
